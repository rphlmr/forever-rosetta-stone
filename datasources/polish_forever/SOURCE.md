# PolishForever

- Upstream and contributor credit: https://github.com/JSlomian/PolishForever
- Language: `plPL`.
- Scope: Quest IDs and English-text hash references. Upstream declares a Haiku translation pass and Sonnet editing; origin remains AI.
- Retained license and attribution: [polishforever-data-license.txt](../../ForeverRosettaStone/notices/polishforever-data-license.txt).

This is an active GitHub datasource. Fetches pin a commit SHA or a published text-only
release asset and retain raw data, source notices and hashes under `datasources/imports/`.
Refreshes build source evidence in SQLite; they never change catalogs automatically.
Keep field authorship and source attribution. A community source is not automatically
higher quality than our existing text. Hash keys are not entity IDs, and unrelated Classic
content must not replace changed Forever content just because an ID matches.

Underlying game content remains Blizzard Entertainment's property. Source code and
translation-data licenses can differ; keep the retained upstream notices when using text.
