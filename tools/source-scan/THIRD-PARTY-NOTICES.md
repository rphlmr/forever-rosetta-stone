# Native hotfix reader

`client_hotfix.py` adapts the XFTH v9 header layout and SStrHash algorithm documented
by [DBCD](https://github.com/wowdev/DBCD) and
[wow.tools.local](https://github.com/Marlamin/wow.tools.local), also implemented in
[wowsims' hotfix reader](https://github.com/wowsims/mop/blob/master/tools/db2tool/wdc/hotfix.go).
